## Project Overview

This project demonstrates **Event Sourcing & CQRS** using Restate's durable execution, replacing traditional message brokers, event stores, and lock managers. The service is a **order management system** with a REST API gateway and Restate‑backed handlers. Clients call the API gateway, which delegates to Restate services for order creation, approval, and state queries.

## Tech Stack

- **Language:** Kotlin 2.2.21 (JVM target 17/21)
- **Framework:** Spring Boot 4.0.0 (Web, Actuator), Restate SDK 2.4.1
- **Runtime:** Restate Server (Docker‑compose) – handles durable execution, state, retries
- **Build:** Gradle with Kotlin DSL (wrapper `./gradlew`)
- **Key libraries:** Kotlin coroutines 1.10.2, kotlinx.serialization, Springdoc OpenAPI (Swagger)
- **Testing:** JUnit5 (no specific assertion library mentioned)

## Build & Run

```bash
# Build everything
./gradlew build

# Run all tests
./gradlew test

# Start Restate server (required first)
docker-compose up -d

# Terminal 1 – run handlers
./gradlew :order-handlers:bootRun

# Terminal 2 – run API gateway
./gradlew :order-api-gateway:bootRun

# Register handler endpoint with Restate
curl -X POST http://localhost:9070/deployments \
  -H 'content-type: application/json' \
  -d '{"uri": "http://host.docker.internal:9080"}'
```

API is then available at `http://localhost:3000`, Swagger at `/swagger-ui.html`.

## Project Layout

```
order-domain/          — domain models, command/event objects, pure Kotlin, no framework
order-handlers/        — Restate service implementations (Virtual Objects, Workflows)
order-api-gateway/     — Spring Boot REST controllers, DTOs, Restate client invocations
docs/                  — architecture diagrams, guides
docker-compose.yml     — local Restate server
```

## Coding Conventions

- **Error handling:** Use Kotlin `Result` or throw domain‑specific exceptions caught by Spring’s `@ExceptionHandler`; no custom Either wrapper observed.
- **Naming:** Services in `order-handlers` are Restate‑annotated classes (`@VirtualObject`, `@Workflow`). Gateway controllers follow `*Controller` convention.
- **Coroutines:** All Restate handlers are suspend functions; avoid blocking calls.
- **Formatting:** Not explicitly enforced, but `./gradlew build` may run ktlint (if configured, not present in snippet).
- **Immutability:** Prefer data classes for domain events and commands.

## Do Not Touch

- `gradle/` wrapper files, `settings.gradle.kts`
- `docker-compose.yml` – only modify if adding new infrastructure, and then in coordination with the team
- Files generated by Restate SDK (client stubs, if any)
